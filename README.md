# 🔐 Cypher AI — CyberSecurity Assessment Tool

A full-stack AI-powered cybersecurity risk assessment platform for **C-level executives and SMEs**. Answer 10 targeted questions and receive an **industry-weighted risk score**, **category insights**, and a **concise executive action plan** — all generated by Google Gemini AI.

---

## ✨ Features

- 🏭 **Industry-weighted scoring** across 5 domains: Access Control, Data Protection, Human Security, Endpoint Security, Incident Response
- 📊 **Executive dashboard** with historical risk trendline
- 🤖 **AI-generated category recommendations** (via Gemini 2.5 Flash)
- 📋 **C-level Action Plan** — synthesized, no jargon, with a 6-month roadmap
- 💬 **Streaming AI Chatbot** with RAG (ChromaDB vector database)
- 🔒 **JWT authentication** with cache-aside persistence (no re-generation for history)

## 🚀 Getting Started

### Prerequisites

- Python 3.11+
- Node.js 18+
- A **Google Gemini API Key**

---

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/Cypher-AI.git
cd Cypher-AI
```

### 2. Backend Setup

```bash
cd backend

# Create and activate a virtual environment
python3 -m venv venv
source venv/bin/activate        # macOS/Linux
# .\venv\Scripts\activate       # Windows

# Install dependencies
pip install -r requirements.txt

# Configure your environment
cp .env.example .env
# Open .env and add your GEMINI_API_KEY and SECRET_KEY
```

### 3. Run the Backend

```bash
# From the backend/ directory, with venv activated:
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

The API will be available at: `http://localhost:8000`
Interactive API docs: `http://localhost:8000/docs`

---

### 4. Frontend Setup

```bash
cd frontend

npm install
npm run dev
```

The app will be available at: `http://localhost:5173`

## ⚙️ Environment Variables

Create `backend/.env` from the template:

```bash
cp backend/.env.example backend/.env
```

| Variable | Required | Description |
|---|---|---|
| `GEMINI_API_KEY` | ✅ Yes | Your Google Gemini API key |
| `SECRET_KEY` | ✅ Yes | JWT signing secret (use a long random string) |
| `DATABASE_URL` | ❌ Optional | Defaults to SQLite. Set for MySQL in production |

---

## 📈 Rate Limits (Free Tier)

The Gemini 2.5 Flash free tier allows **20 requests per day**. If you exceed this:
- The dashboard will display a clear message instead of hanging
- Consider upgrading to a paid Google AI plan for production use

## 🔐 Security Notes

- **Never commit your `.env` file** — it is excluded via `.gitignore`
- Change `SECRET_KEY` to a cryptographically random string before deploying
- For production, switch `DATABASE_URL` to a managed MySQL instance
